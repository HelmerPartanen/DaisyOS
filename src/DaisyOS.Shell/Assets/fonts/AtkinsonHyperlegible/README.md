# Atkinson Hyperlegible

The original Atkinson Hyperlegible family by Braille Institute of America,
licensed under SIL OFL 1.1 (see OFL.txt). These are unmodified Google Fonts TTFs:
https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible

Regular (400), Bold (700), Italic and Bold Italic are embedded in all DaisyOS
Avalonia applications. scripts/install-system-fonts.sh installs these same files
for native Qt/GTK applications; ISO staging installs them machine-wide.
Noto/DejaVu, CJK and emoji fallback remain available. Inter remains a selectable
legacy family. Code and terminal content keep their monospace fonts.
